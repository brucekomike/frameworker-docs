# git repo straper
scripts for batch clone git repositories.

## installation
```
./frameworker mod install https://github.com/brucekomike/bash-straper straper
```

## usage
```plain
Action list:
    help             - show this help
    extract <url> [dir]    - extract env from given url to dir, default to ~/Workspace/
    roll <dir>       - rolling given dir to newest version
Default:
    help
```

# mod
mod is a tool for managing modules, 
mainly act as a downloader and updater.
```{note}
this is just a git warpper, 
so you can clone repos into lib folder manully.
```
## usage
```plain
Action list:
    help             - show this help
    install <URL> <name> - install content from given url
    update <name> - update content by name
Default:
    help
```
